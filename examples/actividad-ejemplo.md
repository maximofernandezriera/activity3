# Actividad evaluable: práctica de programación en Python

## Descripción

El alumnado debe desarrollar una aplicación de consola en Python que gestione
una lista de tareas (añadir, listar, completar y eliminar tareas), persistiendo
los datos en un fichero JSON.

## Requisitos

- El programa debe funcionar correctamente desde la línea de comandos mediante
  un menú interactivo.
- Los datos deben guardarse en `tareas.json` y cargarse al iniciar el programa.
- El código debe estar organizado en funciones y seguir la guía de estilo PEP 8.
- Se debe entregar un `README.md` que explique cómo ejecutar el programa y
  describa brevemente su estructura.
- Se valorará el manejo de errores (entrada inválida del usuario, fichero
  inexistente o corrupto).

## Entrega

Un fichero `.zip` con el código fuente y el `README.md`, a través del aula
virtual antes de la fecha límite indicada.
